Predicting drug--target binding affinity can help prioritize compounds for experimental study. This project implements a Davis-focused MGraphDTA-style regressor that represents each drug as an RDKit molecular graph and each target as an amino-acid sequence. A dense multiscale graph neural network (MGNN) produces a 96-dimensional drug vector; a three-branch multiscale convolutional network (MCNN) produces a 96-dimensional protein vector; an MLP predicts transformed affinity, p$K_d$. The data pipeline constructs 30,056 compound--target records from 68 compounds and 442 target identifiers (379 unique sequences), and uses supplied folds for a 25,046-record training set and 5,010-record test set. The primary seed-42 run used batch size 32, learning rate 0.0005 and 50 steps per epoch. It was manually stopped after 112 of 150 requested epochs; its best validation checkpoint was epoch 91. On the independent test fold it achieved MSE 0.2570, RMSE 0.5070, concordance index 0.8790 and $r_m^2$ 0.6817. Separate experiments include a batch-512 run, an atom-feature scaling comparison with incomplete run metadata, three checkpoint-validated seeds with conflicting process records, and an exploratory protein-graph model. The project reproduces the broad dual-encoder architecture, but default atom scaling and training protocol differ from the author release. Results are exploratory and do not constitute an exact paper reproduction or evidence of causal molecular interactions.
